# x1zz Design System

x1zz.com 브랜드 디자인의 단일 진실 공급원(single source of truth).
디자인을 바꿀 때는 이 문서를 먼저 고치고, 코드를 고친다.

- 버전: **2.1** (2026-09-23)
- 적용 범위: `src/pages/index.astro` (브랜드 랜딩) 및 전역 토큰
- 미적 방향: **"Flat Phosphor"** — 형광 단색 위에 장식을 얹지 않는 계기판/측정기기 미학

---

## 1. 브랜드 원칙

1. **Readability first** — 어떤 이펙트도 가독성을 해치면 제거한다.
2. **장식 금지** — "x1zz"라는 이름처럼 불필요한 것이 없어야 한다. 장식용 문구, hype 카피, 무의미한 터미널, AI가 만든 것 같은 그라데이션은 쓰지 않는다.
3. **색은 하나** — 텍스트·버튼·보더에 그라디언트를 걸지 않는다. 강조는 단색(accent)으로만. 화면에 색이 여러 개 보이면 설계 실패.
4. **이미지가 말한다** — 분위기는 문장이 아니라 이미지 한 장이 만든다. 제너레이티브(오실로스코프 신호) 이미지를 쓴다. 손으로 만든 이미지처럼, 프레임 안의 "기기 출력"처럼.
5. **움직임은 최소** — 스크롤 페이드(0.5s, 소량 translate)만 허용. 타이핑, 무한 루프, 흐르는 띠, 펄스 등 눈에 거슬리는 모든 애니메이션 금지. 레이아웃 시프트를 유발하는 애니메이션은 절대 금지.
6. **성능은 디자인의 일부** — JS 라이브러리 금지, transform/opacity만. LCP < 2.0s.
7. **한 곳에서 정의** — 색·폰트·모션은 `global.css` 토큰으로만.

## 2. 홈페이지 필수 구성 요소 (체크리스트)

| # | 요소 | 역할 | 현재 상태 |
|---|------|------|-----------|
| 1 | **헤더/네비게이션** | 브랜드 노출 + 핵심 경로 | ✅ flat, sticky 없음(단순) |
| 2 | **히어로** | 헤드라인 + 보조 문장 + CTA. 장식 없이 타이포로만 | ✅ |
| 3 | **키 비주얼** | 브랜드 분위기를 담은 이미지 1장. `scripts/gen-art.mjs`로 생성 | ✅ 오실로스코프 신호 |
| 4 | **제품 쇼케이스** | 핵심 제품, 가치 제안 + 정적 파이프라인 + 코드 | ✅ Xazz / Xz |
| 4b | **브리지** | Xz를 웹 프레임워크로 이어주는 next.xz / rails.xz | ✅ 2열 카드, 정적 파이프라인 |
| 5 | **차별화 원리** | 철학 3장 | ✅ |
| 6 | **증거 (Research / Open Source)** | 검증 가능한 실적. 숫자로 | ✅ |
| 7 | **사람 (Founder)** | 사람이 곧 브랜드 | ✅ |
| 8 | **최종 CTA + 푸터** | 이메일, GitHub, 사이트맵 | ✅ |

**제거된 요소** (v1 → v2): 신뢰 티커, 타이핑 터미널, 글로우 오브, 그라디언트 텍스트, 파이프라인 흐름 애니메이션, 상태 펄스 닷.

### 보이지 않지만 필수

- **SEO 메타**: title / description / canonical — `Layout.astro` props
- **OG/Twitter**: 1200×630 — `/og-main.png` (생성: `node scripts/gen-art.mjs`)
- **sitemap / robots.txt**: 페이지 추가 시 `public/sitemap.xml` 갱신
- **접근성**: 대비 4.5:1+, `prefers-reduced-motion`, 키보드 포커스
- **반응형**: 360px ~ 1440px
- **다국어**: EN/KR — `lang-en`/`lang-kr` + `localStorage['x1zz-lang']`

### 3.1 컬러

| 토큰 | 값 | 용도 |
|------|----|----|

| `--color-raised` | `#1A1D23` | 호버 배경 |
| `--color-line` / `--color-line2` | `#262A31` / `#343942` | 보더 |
| `--color-fg` | `#F2F4F8` | 최상위 텍스트 |
| `--color-sub` / `--color-mut` / `--color-dim` | `#C6CBD6` / `#97A0B0` / `#6C7484` | 본문/보조/희석 |
| `--color-accent` | `#00FFA3` | 형광 그린 — 유일한 강조색 |
| `--color-accent2` | `#38C8FF` | Xz 등 이차 구분용 (한 화면 1요소) |

**금지**: 텍스트/보더의 그라디언트 클리핑, 배경 광원(orb), 반투명 컬러 오버레이 레이어.

### 3.2 타이포

| 용도 | 폰트 | 크기 |
|------|------|------|
| H1 히어로 | `--font-sans` 700 | 3.25rem / 2.25rem, `tracking:-0.03em`, `line-height:1.12` |
| H2/H3 | `--font-mono` 700 | 1.5rem / 1.1rem |
| 본문 | `--font-sans` 400 | 1.1rem, `line-height:1.7` |
| 라벨 | `--font-mono` | 0.78rem, `tracking:0.1em` |

### 3.3 레이아웃

- 컨테이너: `max-w-6xl`
- 섹션 간격: `py-16` ~ `py-24`, 카드 `p-6 md:p-8`
- 키 비주얼: 컨테이너 폭, 1px 보더, 하단 라벨바 없음(캡션 없음)

### 3.4 모션

| 항목 | 값 |
|------|----|
| 스크롤 페이드 | `opacity 0→1 + translateY(12px)`, 0.5s `--ease-out-expo` |
| 호버 | border-color / translateY(-2px), 0.15s |
| 그 외 | 전부 금지 |

## 5. 이미지 에셋

이미지는 **스크립트로 생성**한다. 손으로 편집하지 않는다.

```sh
node scripts/gen-art.mjs   # public/hero-wave.jpg + public/og-main.png 재생성
```

| 에셋 | 경로 | 설명 |
|------|------|------|
| 키 비주얼 (1440×810) | `public/hero-wave.jpg` | 오실로스코프 신호: 형광 Lissajous 곡선, 스캔라인, 필름 그레인. 텍스트 장식 없음(기기 HUD 라벨만) |
| OG (1200×630) | `public/og-main.png` | 같은 신호 모티프 + 워드마크 |

생성 원칙: 단색 형광(#00FFA3) + 근흑색 배경, 레이어는 glow(blur) 1개와 선 1개뿐. 이미지 내부 텍스트는 계기 HUD 수준의 최소 라벨만.
